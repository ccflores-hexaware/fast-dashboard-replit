Create a new screen called "Recon" for the FAST Dashboard application following the established modular architecture and UI/UX patterns.

Database Schema
Create a recon table with the following columns:

id (UUID, primary key)
applicationname (text)
accountname (text)
entitlementcolumn (text)
entitlementvalue (text)
filepath (text)
applicationstatus (text)
status (text)
createdAt (timestamp)
updatedAt (timestamp)
Feature Requirements
Read-only screen - No create, update, or delete functionality
No history/versioning functionality - No history tabs, snapshots, or version tracking
Full data viewing capabilities - Table view, card view, search, filter, sort, pagination, and Excel export
